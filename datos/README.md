# Carpeta de datos

Los archivos de origen no se publican en el repositorio porque contienen información confidencial.
Para ejecutar el proyecto, copie aquí los dos Excel con exactamente estos nombres:

- `Bases_Cobranza.xlsx` – bases 2, 3 y 4 (Recaudo, Comité y Gestiones)
- `base 2.xlsx` – base 1 (Reporte1 de SMS)

Se puede usar otra carpeta con la variable de entorno `PT_DATOS`.
